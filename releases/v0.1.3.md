Wildmere now updates itself: download this version once, and future updates arrive in the game.

### New
- **Automatic updates.** Wildmere checks for new versions in the background, downloads them while you play, and installs them when you quit — or right away with "Restart to update" on the title screen. Every update is checked against Wildmere's signing key and its exact file checksum before anything is installed, and the previous version is kept until the new one is safely in place. You can turn automatic downloads off in Settings › Updates.

### Notes
- Earlier versions (0.1.0–0.1.2) can't update themselves: download 0.1.3 from the website once.
- On macOS, keep Wildmere in Applications (or another folder you own). Apps run straight from Downloads without being moved can't replace themselves; the game tells you if that's the case.

### Known issues
- macOS builds are ad-hoc signed, not notarized: approve the first launch in System Settings › Privacy & Security.
- Windows builds are not code-signed: SmartScreen asks for "More info › Run anyway".
- Windows and Intel Macs have only passed automated checks on GitHub's test machines; the game was played and benchmarked on an Apple M4 MacBook Air.
