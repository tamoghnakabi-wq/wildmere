# Wildmere

*Shape the wild.* An original voxel survival sandbox for macOS and Windows, built in Unity 6.3 (URP).
Explore an endless procedurally generated world: snow-capped mountains, temperate and dark forests,
desert dunes and mesas, flower plains, rivers and coasts. Mine it, build in it, and watch the light change.

**Download and install:** see the [Wildmere website](https://github.com/tamoghnakabi-wq/wildmere/releases) and
[docs/INSTALL.md](docs/INSTALL.md). Builds are unsigned (macOS ad-hoc signed, not notarized; Windows unsigned) —
the install guide explains the one-time Gatekeeper / SmartScreen step.

Wildmere is inspired by the voxel-sandbox genre but is an independent, original game: no Mojang/Minecraft names,
code, textures, sounds, logos or branding are used.

## Features
- Infinite deterministic world from a seed: climate-driven biomes with smooth transitions, rivers, lakes,
  caves (caverns + tunnels), ore veins, per-biome trees and plants, and hand-made decoration models.
- Chunk streaming on background threads; greedy-meshed terrain with flood-fill sky/torch light and smooth AO.
- Mining with tools (wood/stone/iron pickaxe, axe, shovel), durability, drops; collision-safe building.
- 36-slot inventory with drag & drop, recipe crafting with workbench and furnace stations.
- Day/night cycle, weather, procedural sky and clouds, water, HD procedural block textures, post-processing.
- Wildlife (deer, rabbits, songbirds) with simple awareness; real-recording ambience and effects.
- Save/load with versioned saves that store only your changes; LOW/MEDIUM/HIGH/ULTRA graphics presets.

## Repository layout
| Path | What |
|---|---|
| `Assets/` | Unity project (all gameplay built at runtime from code; one bootstrap scene) |
| `art-source/` | Reproducible generators: block textures (Python), Blender model scripts, audio pipeline, world-gen tools |
| `website/` | Astro static site (deployed on Vercel) |
| `tools/` | Build/run/test scripts; `tools/release/` packaging + GitHub Release publishing |
| `docs/` | Architecture, install guide, release process, QA report |

## Building
Requires Unity 6000.3.22f1 with macOS (built-in) and Windows (Mono) build support.
```bash
tools/unity.sh WildmereSetup.RunBatch   # one-time project configuration
tools/build.sh mac                       # Build/mac/Wildmere.app
tools/build.sh win                       # Build/win/Wildmere.exe (+ data folders)
tools/run.sh -selftest                   # scripted gameplay checks, exit code 0 = pass
```
See `docs/ARCHITECTURE.md` and `docs/RELEASING.md`.
