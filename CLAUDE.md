# Wildmere

Original voxel survival sandbox (Unity 6000.3.22f1, URP 17.3, C#) plus its Vercel website.
Read `docs/ARCHITECTURE.md` first: world constants, block ids, module ownership, asset
contracts, and the rule to run Unity only through `tools/unity.sh` (2-slot machine lock).
Progress and known issues: `DEVELOPMENT_LOG.md`.
